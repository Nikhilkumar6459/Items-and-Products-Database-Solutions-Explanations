# SQL Assignment 1: Items and Products Database

## Project Description

This project demonstrates practical SQL skills using Microsoft SQL Server (T-SQL). It involves creating databases, designing tables, inserting sample records, and solving Basic, Intermediate, Advanced, and Super-Advanced SQL queries using Items and Products datasets.

The project focuses on data retrieval, filtering, aggregation, data manipulation, subqueries, joins, string functions, and database programming concepts. It also demonstrates the implementation of stored procedures and triggers to perform reusable database operations and automate data updates.

## Project Objectives

- Create and manage databases and tables using SQL.
- Insert, retrieve, filter, update, and delete records.
- Perform calculations using aggregate functions.
- Analyze sales, profit, products, vendors, and country-level data.
- Apply joins, subqueries, grouping, and conditional filtering.
- Create stored procedures for reusable database operations.
- Implement triggers to recalculate gross sales when relevant data changes.
- Use date and string functions for data transformation and analysis.

## Database Structure

The project uses two databases:

**1. Brands Database**

Table: `ITEMS_TABLE`

Contains item descriptions, vendor numbers, vendor names, bottle sizes, and bottle prices.

**2. Products Database**

Table: `PRODUCT_TABLE`

Contains product details, countries, units sold, manufacturing prices, sale prices, gross sales, sales, cost of goods sold (COGS), profit, and date-related information.

## SQL Concepts Covered

- Database and table creation: `CREATE DATABASE`, `CREATE TABLE`
- Data manipulation: `INSERT`, `DELETE`
- Data retrieval and filtering: `SELECT`, `WHERE`, `DISTINCT`, `TOP`
- Aggregate functions: `COUNT`, `SUM`, `AVG`, `MAX`
- Grouping and filtering groups: `GROUP BY`, `HAVING`
- Joins: `INNER JOIN`, `LEFT JOIN`, `FULL
